# Manuscript archive

This directory contains inactive historical manuscript artifacts. The active
sources are [`paper/paper1.tex`](../paper/paper1.tex) and
[`paper/paper2.tex`](../paper/paper2.tex).

- `main.tex` is the former combined manuscript.
- `Collision Geometry and the Jacobian Conjecture.pdf` is the retained build
  of that combined manuscript.
- `paper1-edit.tex` is the former duplicate editing mirror of Paper I. It was
  byte-identical to the active `paper/paper1.tex` when archived on
  2026-08-24.

These files are retained for history only and should not be edited as active
manuscripts.

The archived source retains its historical relative bibliography path and is
not maintained as a standalone build. These non-code materials are licensed
under [CC BY 4.0](../paper/LICENSE).
